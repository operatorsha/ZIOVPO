# Проверка практики 4

Практика 4 добавляет антивирусный движок в Windows-службу и управление сканированием из GUI.

## Подготовка

1. Запусти службу `ZIOVPOPracticeService`.
2. Открой GUI через иконку в трее.
3. Войди:

```text
login: test
password: test
```

4. Активируй лицензию:

```text
DEMO-KEY
```

После активации служба загружает AV-базы в оперативную память. В GUI должна появиться дата выпуска базы и количество записей.

## Тестовые сигнатуры

В базе есть две демонстрационные записи:

```text
EICAR-ZIOVPO-PE
ZIOVPO-SCRIPT-MALWARE
```

Первая предназначена для PE-объекта, вторая - для скриптов.

## Создание тестовых файлов

PowerShell:

```powershell
New-Item -ItemType Directory -Force .\av-test
Set-Content -Encoding ASCII .\av-test\clean.txt "hello"
Set-Content -Encoding ASCII .\av-test\bad.ps1 "Write-Host ZIOVPO-SCRIPT-MALWARE"
```

Для PE-демо:

```powershell
[IO.File]::WriteAllBytes("$PWD\av-test\bad.exe", [Text.Encoding]::ASCII.GetBytes("MZ......EICAR-ZIOVPO-PE"))
```

## Проверка в GUI

1. Нажми `File...`, выбери `clean.txt`, затем `Scan file`.
   Ожидаемо: `CLEAN`.

2. Нажми `File...`, выбери `bad.ps1`, затем `Scan file`.
   Ожидаемо: `INFECTED`, детект `Demo.Script.ZIOVPO`.

3. Нажми `File...`, выбери `bad.exe`, затем `Scan file`.
   Ожидаемо: `INFECTED`, детект `Demo.PE.EicarZIOVPO`.

4. Нажми `Folder...`, выбери папку `av-test`, затем `Scan folder`.
   Ожидаемо: отчёт по папке и найденные заражённые файлы.

5. Нажми `Scan drives`.
   Ожидаемо: запускается сканирование всех несъёмных дисков. Может выполняться долго.

6. Нажми `Schedule`.
   Ожидаемо: для выбранного пути включается сканирование по расписанию раз в 1 минуту.

7. Нажми `Monitor`.
   Ожидаемо: выбранная директория ставится на мониторинг. При создании/изменении файлов служба запускает сканирование этой директории.

## Что говорить на защите

Антивирусная база хранится в оперативной памяти службы как `std::map`: ключом является первые 8 байт сигнатуры, значением - список AV-записей с таким префиксом.

Движок сканирования читает файл как поток байтов и использует автомат Ахо-Корасика для поиска сигнатур. После нахождения кандидатов дополнительно проверяются тип объекта, допустимый диапазон offset, SHA-256 полной сигнатуры и запись из базы. Для обязательной структуры базы также сохраняется `std::map`, где ключом являются первые 8 байт сигнатуры, а значением - список AV-записей с таким префиксом.

Через Windows RPC доступны операции получения информации о базах, сканирования файла, сканирования директории, сканирования несъёмных дисков, настройки расписания и мониторинга директории.
