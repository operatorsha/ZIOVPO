# ZIOVPO: Windows Tray Application and Service

Графическое приложение и Windows-служба для практических заданий ЗИоВПО.

## Задание 1

- при запуске добавляет иконку в область уведомлений панели задач;
- левый клик по иконке открывает главное окно;
- правый клик по иконке открывает контекстное меню;
- контекстное меню содержит пункты `Открыть` и `Выход`;
- после пересоздания панели задач иконка добавляется повторно;
- поддерживает запуск без показа главного окна;
- при закрытии главного окна приложение продолжает работать в фоне;
- главное окно содержит меню `Файл -> Выход`;
- повторный запуск для пользователя блокируется именованным mutex;
- сборка выполняется через CMake.

## Задание 2

Добавлена Windows-служба `ZIOVPOPracticeService` и взаимодействие с графическим приложением через Windows RPC с транспортом ALPC (`ncalrpc`).

Служба:

- запускает `ZIOVPOTrayApp.exe --background` во всех доступных пользовательских сессиях, кроме сессии 0;
- запускает графическое приложение от имени владельца терминальной сессии;
- отслеживает входы, разблокировки и подключения пользователей;
- не принимает управляющие сигналы Stop и Shutdown от SCM;
- поднимает RPC-сервер `ZIOVPOPracticeRpc`;
- завершает запущенные графические приложения при остановке через RPC.
- настраивает DACL процесса службы: полный доступ остаётся у `SYSTEM` и `Administrators`, обычные пользователи не получают право завершения процесса;
- запускает графическое приложение с DACL процесса, в котором обычным пользователям не выдаётся право завершения процесса.

Графическое приложение:

- при старте проверяет состояние службы;
- если служба остановлена, пытается запустить её, ждёт состояния `Running` и завершает работу;
- если служба запущена, проверяет, что родительский процесс является процессом службы;
- пункты `Файл -> Выход` и `Выход` в меню трея отправляют RPC-команду остановки службы.

## Локальная сборка

Требования:

- Windows;
- Visual Studio 2022 с компонентами C++;
- CMake 3.20 или новее.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Готовый exe:

```text
build/Release/ZIOVPOTrayApp.exe
build/Release/ZIOVPOService.exe
```

## Установка и запуск службы

Команды нужно выполнять в PowerShell или CMD от имени администратора из папки, где лежат оба exe-файла:

```powershell
sc.exe create ZIOVPOPracticeService binPath= "%cd%\ZIOVPOService.exe" start= demand
sc.exe start ZIOVPOPracticeService
```

После запуска служба сама создаст графическое приложение в пользовательской сессии. Главное окно будет скрыто, а иконка появится в области уведомлений.

Удаление службы:

```powershell
sc.exe delete ZIOVPOPracticeService
```

## Ручной запуск приложения

Обычный запуск:

```powershell
.\build\Release\ZIOVPOTrayApp.exe
```

Запуск в фоновом режиме, без показа главного окна:

```powershell
.\build\Release\ZIOVPOTrayApp.exe --background
```

Также поддерживаются аргументы `--hidden`, `/background`, `/hidden`.

Начиная с задания 2 ручной запуск используется только для проверки логики старта службы. Если приложение запущено не службой, оно завершится после проверки.

Если рядом с `ZIOVPOTrayApp.exe` лежит файл `open.mp3`, приложение проигрывает его при открытии главного окна.
